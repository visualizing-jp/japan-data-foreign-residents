# データソース

正本。パースや指標の定義はここを先に直す。

## 調査

- 総務省「住民基本台帳に基づく人口、人口動態及び世帯数」（統計コード `00200241`）
- 公表ページ: https://www.soumu.go.jp/main_sosiki/jichi_gyousei/daityo/jinkou_jinkoudoutai-setaisuu.html
- 過去年次: e-Stat ファイル配信（API ではない）

## 列・軸（一次確認済み: 令和8年＝2026）

### 人口・動態（都道府県）

- 団体コード / 都道府県名
- 人口: 男 / 女 / 計、世帯数
- 動態（前年暦年）: 住民票記載（転入国内・国外・出生・その他…）、消除（転出・死亡・帰化等…）、増減数、増減率、自然増減、社会増減

市区町村表は列構成が同型で、市区町村名列が追加される。都道府県計行は市区町村名が `-`。

### 年齢階級

- 団体コード / 都道府県名 /（市区町村名）/ 性別 / 総数 / 0歳～4歳 … / 100歳以上
- 性別: 計・男・女
- 注: 秘匿市区町村がある場合、内訳合計と総数が一致しない

## 指標

| 指標 | 定義 |
| --- | --- |
| `pop` | 外国人住民人口 |
| `households` | 外国人住民の世帯数（総数のみ） |
| `growth` / `growthRate` | 表の増減数・増減率（総数のみ） |
| `share` | 外国人人口 ÷ 総計人口（男女別も同定義） |

## 断絶・注記

- **2013年（平成25年）**: 基準日が **3月31日**。以降は原則 **1月1日**。
- 在留カードの性別空欄は男女いずれにも含めない（公表注記）。
- 年齢階級の秘匿セルは欠測（null）。隠さず注記する。

## 配信チャンク

| ファイル | 内容 |
| --- | --- |
| `era.json` | 全国+47県 × 性 × 年 → pop / households / growth / growthRate / share |
| `age.json` | 同上 × 年齢階級 → pop |
| `geo.json` | 最新年の県 Cube + 市区町村 Cube |
| `age-city.json` | 最新年の市区町村 × 性 × 年齢 |
| `meta.json` | 年一覧・出典・注記 |
